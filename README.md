# HRM Frontend

React, Vite, TypeScript, Tailwind CSS, React Router DOM, React Hook Form, Zod,
TanStack Query, TanStack Table, Recharts, Sonner, and Lucide React.

## Commands

```bash
npm run dev
npm run build
npm run lint
```

The frontend follows `.agent/rules/HRM.md`: reusable form controls, API
services, permission-aware UI, loading/error/empty states, and responsive ERP
layout.
